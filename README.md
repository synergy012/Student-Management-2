# Student Management 2

A web-first student management system for managing applications, admissions, annual enrollment, tuition, financial aid, tuition contracts, Kollel compensation, communications, reporting, and configuration.

## Core principles

- One permanent student record
- Year-specific enrollment and financial history
- Native web forms; no PDF-based workflows
- Configuration-driven business rules
- Complete audit history
- Live workflow dashboards
- AI-friendly development process
